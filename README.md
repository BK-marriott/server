# 🏨 BK-Marriott
>호텔 체인점 예약 시스템</br>
> 개발 기간 : 2024.12.23 ~ 2025.01.27

저희 프로젝트는 5,000개 호텔과 100만 개 객실을 보유한 대규모 호텔 체인의 예약 시스템 구축을 목표로 합니다. <br>
고객은 웹사이트에서 프로모션을 통해 쿠폰을 발급받고, 객실 조회, 예약, 결제 과정을 원활하게 처리할 수 있는 서비스를 제공합니다.
